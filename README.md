# Anlamsız Cümle Üretici

## Bu Proje Nedir?

Bu, insanlık tarihinin en önemli icadıdır. Anlamsız Türkçe cümleler üreten bir algoritmadır. Belki de hayatın anlamını bulamayız ama en azından "Kedi dans etti ayın altında" diyebiliriz.

**UYARI:** Bu kodu çalıştırmak beyninizi resetleyebilir. Sorumluluk kabul etmiyoruz. Ciddiye almayın ama çok ciddiye alın.

## Nasıl Çalıştırılır?

```bash
python uretici.py
```

Ve işte! 7 tane anlamsız cümle. Daha fazlası için kodu aç ve range'i değiştir. Profesyonelce.

## Özellikler

- %100 anlamsız
- %0 faydalı
- %200 eğlenceli
- Türkçe destekli (tabii ki)

## Katkıda Bulunmak

Lütfen katkıda bulunmayın. Bu mükemmellik zaten zirvede. Ama eğer illa istiyorsanız, daha anlamsız kelimeler ekleyin.
